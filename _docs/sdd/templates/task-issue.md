## Acceptance criteria

- [ ] AC-01: Concrete result.
- [ ] AC-02: Important negative/retry/lifecycle behavior, if relevant.

## Verification plan

For each criterion, give the scenario or exact available command, expected result, test environment, and evidence to collect. Include safeguards for tests touching data or external side effects. Do not invent a passing run.

## Delivery conditions

State whether acceptance requires local verification, merge, hosted proof, production deployment, or another agreed condition. Publishing/deploying remains separately authorized.

## Completion record

Append implementation, review, verification, and acceptance comments using the evidence template. Set workflow status to verified after the agreed checks; close only after explicit acceptance and delivery conditions are met, or explicit cancellation.
