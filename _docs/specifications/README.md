# Specifications

Create actual behavior contracts here using [the specification template](../sdd/templates/specification.md) and [guide](../sdd/guides/specifications-guide.md).

Naming: `SPEC-NNN_<slug>.md`, for example `SPEC-001_task_capture.md`. This example is not an allocated ID or an approved spec.

Link implementation tasks by their real GitHub issue URLs. Do not maintain a local task-status table or duplicate issue bodies here. No implementation spec has been approved by installing the SDD package.
